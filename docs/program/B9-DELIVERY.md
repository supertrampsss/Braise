# B9 : studio créateur

Choix éditoriaux approuvés, un à douze éléments, cinq titres, ordre modifiable au clavier, suppression, aperçu structurel, brouillon serveur avec comparaison de révision et reprise. Les modifications non enregistrées ne sont pas remplacées silencieusement : navigation interne protégée, avertissement avant sortie et rechargement explicite. Le retrait d’une édition ne remplace que la liste des éditions dans l’éditeur.

Publication d’une copie immuable avec les références de corpus V1 exactes capturées : une réorganisation ultérieure du catalogue ne réinterprète pas l’édition. Une modification du brouillon ne change pas les liens déjà publiés. Le retrait bloque lecture, progression, entrée et voies génériques de partie. Les participants ne reçoivent ni liste future ni graines. Les réussites serveur débloquent la prochaine étape et le lien de retour conserve le parcours. Les collections se recoupent : aucune promesse de cibles distinctes dans une création.

Affichage streamer séparé : températures et nombre de propositions, sans mot ni annonce de solution. Actualisation manuelle explicitement annoncée, pas de faux temps réel. Son API actuelle est celle de la partie autorisée ; la projection visuelle écarte les mots.

Tests SQLite : propriété, validation éditoriale, conflit de brouillon, édition stable, reprise, retrait et barrière générique. Relecture Astra avec correction de perte d’édition locale. Publication privée et qualification hébergée à constater séparément ; aucun test navigateur effectué. L’accès à une édition est par lien et identité invitée dans le Site privé, pas une invitation nominative indépendante.
