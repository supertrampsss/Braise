# Generated semantic assets

This public GitHub mirror contains the complete Braise application source, tests, editorial data and project documentation from Sites source commit 5f349c1f1eaf0dc114bc85cbfa9a4fe3c69e23da.

The following generated runtime assets are intentionally not copied to the public repository because GitHub's safety review cannot inspect the compressed BRZ payloads:

- public/semantic/fr-fasttext-30000-v1/targets/*.brz
- data/semantic-fr.json
- public/semantic/fr-fasttext-30000-v1/source.json

They remain preserved in the canonical Sites source and in the private online deployment. Their manifests, generation and verification scripts, tests and documentation remain in this repository. No secret or user data is involved.
